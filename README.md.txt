# Movie Ticket Booking FastAPI Project

## Project Description
This is a Movie Ticket Booking backend system built using FastAPI.
It allows users to register, manage movies, search movies, book tickets,
confirm tickets, cancel tickets, and view dashboard statistics.

## Features Implemented

- User Registration API
- View Users API
- Delete User API
- Add Movie API
- View Movies API
- Update Movie API
- Delete Movie API
- Movie Search API
- Movie Sorting API
- Movie Pagination API
- Seat Availability Check API
- Ticket Booking API
- View Tickets API
- Confirm Ticket API
- Cancel Ticket API
- Ticket Pagination API
- Dashboard Statistics API

## Tech Stack Used

- FastAPI
- Python
- Pydantic
- Swagger UI
- REST APIs

## How to Run Project

Run:

uvicorn main:app --reload

Open:

http://127.0.0.1:8000/docs
